# Technische Spezifikationen

## Technologie

Um die Website modular zu gestalten und für zukünftige Entwicklungsanforderungen vorzubereiten, wird PHP verwendet. 

## Refaktorisierung

Die derzeitige Datei „index.html“ wird in „index.php“ umbenannt, und wiederverwendbare Teile wie Kopf- und Fußzeile werden in die Dateien „header.php“ und „footer.php“ ausgelagert.

## Neue Seiten

Es werden die folgenden Dateien erstellt, die den einzelnen in den User Stories genannten Seiten entsprechen:

- uber-uns.php (US-006)
- agb.php (US-005)
- kontakt.php (US-007)

Diese Seiten werden header.php und footer.php wiederverwenden.
