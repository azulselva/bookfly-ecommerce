# E-02 · Informationsseiten

## US-005 AGB
**Als** Kunde 
**möchte ich** die AGB klar einsehen können, 
**um** sie zu verstehen und meine Rechte und Pflichte zu kennen.

### Akzeptanzkriterien
- Im Menü des Footers sollte es einen Link zu den AGB geben.
- Die Seite soll die vollständigen AGB enthalten.


## US-006 Uber uns
**Als** Kunde 
**möchte ich** die Werte und Geschichte des Unternehmens kennen, 
**um** zu wissen, ob sie mit meinen Werten übereinstimmen und ich dort kaufen soll.

- Sowohl im Hauptmenü als auch im Footer-Menü sollte es einen Link zur „Über uns“-Seite geben. 
- Die Seite soll eine Beschreibung der Werte, Philosophie, Ziele und Geschichte des Unternehmens enthalten.

Sowohl im Hauptmenü als auch im Footer-Menü sollte es einen Link zur Seite „Kontaktdaten“ geben. 
Die Seite soll die statischen Kontaktdaten enthalten.

### Akzeptanzkriterien

## US-007 Kontaktformular
**Als** Kunde 
**möchte ich** einen Button für das Kontaktformular finden, 
**um** direkt mit dem Unternehmen kommunizieren zu können.

### Akzeptanzkriterien
- Sowohl im Hauptmenü als auch im Footer-Menü sollte es einen Link zur Seite „Kontaktdaten“ geben. 
- Die Seite soll die statischen Kontaktdaten enthalten.
